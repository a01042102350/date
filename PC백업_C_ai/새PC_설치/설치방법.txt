[데스크탑(다른 PC)에서 월마감 작업하기 — 처음 한 번만]

준비물: 그 PC에 엑셀, VS Code + Claude Code 설치

방법 1) GitHub에서 받기 (추천)
  1. https://github.com/daeshin-novix/novix-finance-yunheeseung 에 로그인해서 들어감
  2. 초록 "Code" → Download ZIP → 압축 풀기
  3. 그 안의 "참고자료\새PC_설치" 폴더에서 "새PC_설치.ps1"을 마우스 오른쪽 → "PowerShell에서 실행"
     (실행이 막히면: 시작 → PowerShell 열고
      powershell -ExecutionPolicy Bypass -File "폴더경로\새PC_설치.ps1")
  4. 로그인 창이 뜨면 GitHub a01042102350 계정으로 로그인
  또는 그 PC의 클로드에게 "회사 저장소 참고자료\새PC_설치 로 설치해줘"라고 말하기

방법 2) 이 폴더(새PC_설치)를 USB·메일로 옮겨서 위 3~4번

설치되면
  - C:\ai\도구, C:\ai\CLAUDE.md, C:\ai\기초자료, 참고자료, 클로드 메모리가 노트북과 똑같이 생김
  - 10분마다 C:\ai ↔ GitHub 자동 동기화 → 노트북에서 바꾼 파일이 데스크탑에도, 데스크탑에서 바꾼 파일이 노트북에도
    (더 새 파일이 이김. 지운 파일은 다른 쪽에서 지워지지 않음)

주의
  - 두 PC에서 동시에 같은 파일 작업 금지 (한쪽에서 끝내고 10~20분 뒤 다른 쪽에서)
  - 엑셀로 열어 둔 파일은 닫아야 동기화됨
