## 3. 해외매출 자동전표 (핵심)

### 3-1. 무엇을 읽나

- **수출 최종본** `2026년 수출 (YYYY.MM)_M월반영.xlsx`의 이번 달 시트 `YY.MM(NEW)`
  - 'BL일자' 등 머리글 위 '◆' 줄 + 3줄부터 '총계' 줄까지
  - 칸: A 거래처, B 공장, C 인보이스, D 면장번호, F BL일자, G 환율, H 외화, I 원화, K 이월
- **라인별 금액:** `■…인보이스별 상세■.xlsx`의 사형·자동·금형 주조·가공1·가공2·가공3 칸
  - '인보이스' 머리글 줄을 찾아 읽음
  - 같은 이름 파일이 여러 개면 가장 최근 것
- **신코·코마츠(엔화) 라인 금액:** 지출품의서 마감의 **그 달 시트만** 읽음. 칸은 사형·금형·가공(→가공3)·스크랩(사형)·스크랩(금형)·계
- **거래처·사업장 설정표:** `해외전표_거래처.csv`, `해외전표_사업장.csv`
- **업로드 양식:** `해외자동전표\자동전표처리(일반) 양식.xlsx`
  - 1~3행은 머리글이고, 4행부터 채움
  - 양식을 복사해서 씀

### 3-2. 전표로 만들지 않는 줄

| 줄 | 이유 |
|---|---|
| 다음 달 이월 (K열 '이월' 칸에 수식이 있는 줄, 회색) | 이번 달 매출 아님 |
| ATLAS (아트라스콥코) | 국내 전자세금계산서 매출이라 해외매출 전표 아님 |
| 인보이스가 `DSM0000-…` 또는 `0000P…` 형식이 아닌 줄 | '8월 오기재 관세 차액분' 같은 정정 줄 → **에러**로 알리고, 사람이 해당 전표에 직접 반영 |
| 원화 0원 | 무상 샘플 등 → **알림** |

### 3-3. 전표 1장의 모양 (인보이스 1건 = 전표 1장, 관세 줄은 따로 1장)

| 줄 | 차대 | 계정 | 금액 | 그 밖에 넣는 칸 |
|---|---|---|---|---|
| 국외매출 (라인마다 1줄) | 대변(4) | 4140000 | 라인별 금액 | 프로젝트, 적요 끝에 `-라인이름` |
| 부가세예수금 | 대변(4) | 2550000 | **0** | 부가세사업장, 세무구분 **16**, 공급가액 = 원화, 환종, 외화금액, 환율, 수출신고번호 |
| 외상매출금 | 차변(3) | 1080000 | 원화 | 증빙코드 **9**(기타) |

- 모든 줄: 회계단위 **1000**, 같은 작성일자·작성번호, 라인순번 1·2·3…, 거래처코드·거래처명
- **모든 줄의 관리항목:** T 환율, U 외화금액, V 세무구분 16 (3-4 참고)
- 차변 합계 = 대변 합계를 전표마다 확인합니다.

### 3-4. 업로드 양식 칸 (A~V)

| 칸 | 이름 | 넣는 값 |
|---|---|---|
| A | 회계단위 | 1000 |
| B | 작성일자 | BL일자 `yyyyMMdd` (텍스트) |
| C | 작성번호 | **날짜마다 1000, 1001, 1002 …** (손으로 넣는 전표 번호와 안 겹치게) |
| D | 라인순번 | 1부터 |
| E | 차대구분 | 3 = 차변, 4 = 대변 |
| F | 계정과목 | 4140000 / 2550000 / 1080000 |
| G | 거래처 | 거래처코드 **텍스트**(앞자리 0 유지, 예: 01374) |
| H | 거래처명 | 설정표 이름 |
| I | 계정금액 | 원 단위 |
| J | 증빙코드 | 외상매출금 줄만 9 |
| K | 적요 | 3-5 참고 |
| L | 부가세사업장 | 부가세 줄만 (3-8) |
| M | 세무구분 | 부가세 줄만 16 (영세율 수출, 사용자 확인) |
| N | 공급가액 | 부가세 줄만 원화 |
| O | 환종 | 부가세 줄만 USD / JPY / KRW |
| P | 외화금액 | 부가세 줄만 (KRW면 원화) |
| Q | 환율 | 부가세 줄만 (JPY는 **100엔 기준**, KRW는 1) |
| R | 수출신고번호 | 부가세 줄만, 면장번호가 `00000-00-000000X` 형식일 때 |
| S | 프로젝트 | 국외매출 줄만 |
| T | 환율 (EXCH_RT, 관리항목 H5) | **모든 줄.** 부가세 줄 Q와 같은 값 (엔화 100엔 기준, 원화수출 1) |
| U | 외화금액 (FORE_AM, 관리항목 I5) | **모든 줄.** 부가세·외상매출금 줄 = 인보이스 외화 전체. 국외매출 라인 줄 = 외화를 라인 원화 비율로 나눈 값 |
| V | 세무구분 (CT_DEAL, 관리항목 K1) | **모든 줄** 16 |

- 텍스트로 넣는 칸: A, B, G, H, J, K, L, M, O, R, S, V
- 엑셀 셀 서식을 `@`로 둔 뒤 값을 넣습니다.
- **쉼표 표시:** 값은 숫자 그대로 두고 표시 형식만 바꿉니다.
  - I 계정금액, N 공급가액: `#,##0`
  - P·U 외화금액: `#,##0.00`
  - Q·T 환율: `#,##0.00##`
- **U 외화금액 나누는 법:** 국외매출 라인 외화 = 인보이스 외화 × (라인 원화 ÷ 전체 원화)를 소수 둘째 자리로 반올림합니다. 끝수는 가장 큰 라인에 더해, 라인 합계가 인보이스 외화와 똑같게 합니다.
  - 외화는 수출 파일 값을 그대로 씁니다. 관세처럼 소수 셋째 자리가 있으면 그대로 둡니다(예: 22,594.495).

### 3-5. 적요 규칙 (2026-11-11 사용자 결정)

형식: **`인보이스 금액*@환율 -라인이름`**
- **품명은 넣지 않습니다.**
- 부가세 줄과 외상매출금 줄에는 `-라인이름`을 붙이지 않습니다.

| 경우 | 예 (금액은 예시) |
|---|---|
| 달러 | `DSM2610-05 $10,000.00*@1,342.40 -금형1` |
| 엔화 | `DSM2610-JS01 ¥1,000,000.00*@842.3000 -사형1` |
| 원화수출 (BERGEN) | `DSM2610-R01 \10,000,000 -사형` (환율 없음) |
| 관세 | `DSM2610-AL01(관세) $10,000.00*@1,342.40 -자동` |
| 툴링비 | `DSM2610-25(툴링비) $1,000.00*@1,338.60 -가공2` (인보이스에 '(툴링비)'가 없으면 붙임) |

- **달러 환율:** 수출 파일 환율 칸에 **보이는 그대로**(소수 둘째 자리, 쉼표)
- **엔화 환율:** 수출 파일 값(1엔당, 예 8.4230) **× 100, 소수 넷째 자리** → `842.3000` (3-6 참고)

### 3-6. 통화별 처리

| 통화 | 부가세 줄 환종 | 외화금액 | 환율 칸 | 원화 |
|---|---|---|---|---|
| USD | USD | 달러 | 수출 파일 환율 (예 1342.4) | 수출 파일 원화 |
| **JPY** | JPY | 엔 | **100엔 기준** (수출 파일 8.4230 → **842.3**) | 수출 파일 원화. 매출내역서 원화와 다르면 **매출내역서 원화**(알림) |
| KRW (BERGEN 원화수출) | KRW | 원화 | 1 | 수출 파일 원화 |

**엔화 계산을 이해하는 법**
- 엔화 환율은 원래 **100엔당**으로 고시됩니다(서울외국환중개 매매기준율). 예: 100엔 = 842.30원
- 수출 파일은 이것을 100으로 나눠 **1엔당 8.4230**으로 적습니다. 원화 = ROUNDDOWN(엔 × 8.4230)
- **아마란스는 엔화 환율을 100엔 기준으로 받습니다.** 9월 실제 엔화 전표 14줄이 모두 그랬습니다(예: 환율 862.15, 외화 × 환율 ÷ 100 = 원화). 그래서 전표에는 842.3을 넣습니다.
- 어느 쪽이든 원화는 같습니다. 예: ¥1,000,000 × 8.4230 = ¥1,000,000 × 842.30 ÷ 100 = 8,423,000원

3. 전표마다 차변 = 대변
4. 거래처코드 빈 줄 0
5. 엔화 전표: 외화 × 환율 ÷ 100 = 공급가액
6. 적요 환율 = 수출 파일 환율(달러는 보이는 그대로, 엔화는 × 100)
7. 작성번호: 날짜마다 1000부터, 빠짐·겹침 없음
8. 관리항목: T·U·V가 빈 줄 0, 전표마다 국외매출 라인 외화 합 = 외상매출금 외화 = 부가세 줄 외화

## 4. 회계 수출 파일 채우기 (③, 요약)

- **바탕:** 그 달 폴더의 `2026년 수출 (YYYY.MM).xlsx`. 없으면 지난달 결과 파일을 바탕으로 씁니다.
- 전월 시트를 복사해 `YY.MM(NEW)`를 만들고, **그 달 기초자료 값만** 채웁니다. 결과는 새 파일 `…_M월반영.xlsx`입니다.
  - 작업 폴더의 임시 파일에서 만들고, 성공해야 결과 파일과 바꿉니다.
- **기초자료 두 개를 서로 비교 검증합니다:** 인보이스, BL날짜, 환율, 달러, 원화 계. 검증 결과는 'M월 기초자료 검증' 시트에 넣습니다.
- **칸**
  - Invoice, 면장번호, BL일자, 외화
  - 환율 `=VLOOKUP(BL일자,환율!A:B,2,0)`
  - 원화 `=ROUNDDOWN(외화*환율,0)`
  - 전월이월·당월출하 칸 = 원화, 이월은 이월 칸에만
- **색**
  - 녹색: 전월에서 넘어온 매출
  - 회색: 다음 달로 이월
  - 연한 파랑: 툴링·관세. 툴링은 인보이스 뒤에 "(툴링비)"
- **관세**는 상세 파일 'ALLISON 관세' 시트, **툴링**은 '툴링비+PPAP' 시트에서 읽습니다.
- **신코·코마츠:** 지출품의서 마감의 그 달 시트만 씁니다. 환율은 숫자 그대로이고, 인보이스 YYMM이 전월이면 녹색입니다.
- **환율 검증:** 서울외국환중개 매매기준율과 비교합니다(휴일은 앞 영업일, 엔화는 100엔 값 ÷ 100). 틀린 환율은 고치지 말고 빨간색만 칠하고 알립니다.
- **다시 만들 때:** 기존 결과를 백업하고, 유니패스·면장번호·메모를 인보이스별로 읽어 되살립니다.
- **시트 모양은 바꾸지 않습니다.** 줄과 시트를 추가하는 것만 됩니다. 거래처가 바뀌는 줄 아래에는 굵은 선을 긋습니다.
- **처음 보는 거래처**는 같은 공장 마지막 거래처 아래에 넣고 알립니다. 툴링비 거래처를 모르면 멈춥니다.

## 8. 클로드 기술 메모 (스크립트를 고치거나 새로 만들 때)

- **환경:** Windows PowerShell 5.1과 엑셀 COM. 스크립트는 **UTF-8(BOM)**으로 저장합니다. CSV도 BOM을 붙여야 엑셀에서 한글이 안 깨집니다.
- **PowerShell 변수는 대소문자를 구분하지 않습니다.** `$S`와 `$s`, `$M`과 `$m`처럼 겹치지 않게 짓습니다.
- **문자열 안의 변수:** `"$변수한글"`은 `"$($변수)한글"`로 씁니다.
- **실행 출력을 `Select-Object -First N`으로 자르지 않습니다.** 스크립트가 중간에 멈춥니다.
- **`RD`, `CD` 같은 이름으로 함수를 만들지 않습니다.** `RD`는 Remove-Item(삭제)의 별칭입니다.
- **엑셀 COM**
  - 끝나면 `Quit()`과 `ReleaseComObject`를 합니다. 창 없이 남은 EXCEL.EXE가 파일을 잡을 수 있습니다.
  - 2차원 배열은 `SetValue`로 넣습니다.
  - 엑셀 COM을 쓴 같은 프로세스에서는 윈도우 OCR의 `OcrResult.Text`가 비므로, `Lines`를 모아서 씁니다.
- **엑셀 없이 xlsx 읽기:** `C:\ai\도구\엑셀없이_xlsx읽기.ps1`(`Read-Xlsx 경로 시트번호`). 빠르고 엑셀 창 문제가 없습니다.
- **텍스트 칸:** 거래처코드처럼 앞자리 0이 있는 칸은 셀 서식 `@`를 먼저 주고 넣습니다.
- **VBA 매크로**
  - VBA 문자열에 `—`, `✖`, `·` 같은 기호를 쓰면 `?`로 깨집니다.
  - 버튼과 매크로는 `도구\매크로_만들기.ps1`로 고칩니다. VBA 접근 설정을 잠깐 켰다가 되돌리고, 끝나면 값을 확인합니다.
- **결과 파일을 다시 만들 때:** 백업, 사용자 입력 되살리기, 임시 파일에서 만들고 성공하면 바꾸기, 이 세 가지를 반드시 지킵니다.
