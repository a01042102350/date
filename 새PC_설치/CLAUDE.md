## 해외
- 기준은 **회계 파일**. BL날짜·인보이스: 해외 = N월라인, 국내 = 출하일(MES 출고일, 빨간색 없음), 신코·코마츠 = 매출내역서 엑셀.
- mes 시트 **체크 칸**(사람이 직접 체크): 인보이스 번호와 수출면장 번호 사이에 불량·이월·반품·관세·툴링비 = 숫자 1이면 ☑, 0이면 ☐(서식). 칸 선택 → 1 → Enter, 여러 칸은 선택 → 1 → Ctrl+Enter. 반영을 다시 해도 체크 내용은 지우지 않음. HTML MES 탭에도 체크박스 + '체크 저장' 버튼 → 체크_YYYYMM.json(엑셀과 달라진 칸만)을 월 폴더에 두면 다음 반영 때 엑셀에 합치고 '체크_반영됨_…'으로 이름 바꿈. HTML 표의 '확인'·'#' 칸은 없앰.
- mes 시트 **줄 정렬**(2026-10-31): 국내 위 · 해외 아래(굵은 선), 각각 품번 → 출고일 순. NO는 MES 원래 번호 그대로(체크 기록 기준). 정렬로 줄이 바뀌면 오류원본 'MES 행'도 새 위치로 바꿈. HTML MES 탭에 '▼ 국내 / ▼ 해외' 제목 줄.
- mes 시트 열 순서(2026-10-31): … 인보이스 번호 | 불량·이월·반품·관세·툴링비 | 수출면장 번호 | 담당자 | 출고Lot | 구분 | 고객사 | … | 금액 | 전자세금계산서 금액 | 환율 | 기초자료환율 | 달러 | 기초자료달러 | 6칸 | 세금계산서 일련번호 | 메모(맨 끝). 환율(smbs.biz BL일 매매기준율, Bergen은 회계 1,350), F 기초자료환율, G 달러(MES 금액 ÷ 환율), H 기초자료달러(N월라인/매출내역서 금액을 MES 금액 비율로 나눔), 금액 옆 '전자세금계산서 금액', 맨 끝 '세금계산서 일련번호'(여러 개면 한 줄에 하나씩).
- 회계 면장번호 칸 **회색 = 무조건 다음 달 이월** (BL이 이번 달이어도).
- 출고Lot 오기(예: DSM2608-AL6 = AL06)는 비슷한 번호 하나로 인식, 에러 아님.
- 메모에 **Replacement** = 교체품 → 금액·달러·기초자료달러 0이 정상, 에러 아님.
- MES 출하 기준 금액 ≠ 확정 금액(회계·인보이스) = **출하기준 금액변동**(에러 아님) → 출하금액변동 시트. mes 달러 칸은 연한 노랑(제출본).
- **신코·코마츠**: 기초자료 "N월신코, 코마츠 지출품의서마감.xlsx"에서 **탭이 색칠된 시트만** 읽음(표 머리글 인보이스/BL날짜/환율/엔화금액/사형/금형/가공/스크랩(사형)/스크랩(금형)/계, '합계' 줄에서 멈춤). 인보이스 앞 "NN-" = 월(이번 달보다 크면 이월). 엑셀에 없고 회계가 회색이면 이월(예: JS03). 엑셀 엔화 소수점(예: SK03 9,339,379.52) → **회계(9,339,380)가 맞음**, 매달 **알림**(노란 줄)으로 보여 줌.
- 아트라스콥코 = **국·해외**: 회계 면장 칸 '전자세금계산서' → 국내매출에서 세금계산서와 비교(이번 달 매출 = 회계 원화).

## 국내 (MES · 일별마감 · 세금계산서 3자 비교, 고객사별 1줄)
- 목적: 반품·불량으로 들어왔다 다시 나가 MES 수량·금액이 바뀐 것 찾기. MES에는 반품이 없고 일별마감에 있음.
- 일별마감(YYMM 시트): 고객사별 **하늘색 소계(=SUM) 범위 = 이번 달 매출 = 세금계산서**. 소계가 있는 고객사의 범위 밖 줄은 비고 없어도 **이월** → 이월매출(구분 국내). 비고 '10월이월' 등도 이월. '불량반출'은 참고만. 날짜·품번 없는 소계 줄은 뺌. 라인 줄임말은 전체 이름으로(생·구는 뜻 미확인).
- MES 출고 vs 일별마감 이번 달 출하: 일별이 적으면(−) **반품·불량**, 많으면(+) **단가 소급**으로 봄 → 에러 아님(연한 노랑, "MES와 일별마감 차이로 판단"). 한쪽에만 있으면 에러(예: 알멕 = MES 출고 입력 누락).
- MES 금액이 비어 있는 국내 행(메모 Replacement 아님) = **불량대체**(국내 영업팀 확인 2026-10-30) → 정상, 참고. mes '전자세금계산서 금액' 칸에 "불량대체". 일별마감 금액 칸에 "불량대체"(금액은 비고)인 줄도 매출 아님 → MES와 차이가 불량대체 금액과 같으면 불량대체로 설명.
- 일별마감 이전 달 시트(2608 등)의 "N월이월" 줄 중 이번 달 시트에 없는 것이 MES 이번 달에 출고되기도 함(예: 브이텍스 8월 시트 422행) → 아직 규칙 미정(검토 중).
- 세금계산서: **작성일** 기준으로 월 판단(다음 달 발급 수정세금계산서는 작성일이 이번 달이면 포함). 다른 달 작성분은 비교 제외. 거래처명 대응: 에스앤티=SNT, 아트라스콥코코리아=ATLAS KOREA, 이름이 여러 곳과 비슷하면 MES 금액이 같은 곳. **제품 외 매출**(고철·AL재·차량매각·임차료·외주가공비, 못 맞춘 거래처)은 비교 안 함.
- mes '전자세금계산서 금액'은 고객사 합계가 세금계산서와 맞으면 **MES 금액 그대로**, 일련번호는 그 작성일 세금계산서 번호들.
